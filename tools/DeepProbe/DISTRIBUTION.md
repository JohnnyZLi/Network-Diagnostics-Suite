# Network Deep Probe

This archive contains the command-line native companion for Network Diagnostics Suite. It runs locally, performs operating-system-level network tests, and writes JSON that can be opened at `https://network.johnnyli.dev`.

The binary is self-contained; the .NET runtime does not need to be installed.

## Run

Windows 11:

```powershell
.\NetworkDeepProbe.exe
```

macOS or Linux:

```bash
chmod +x NetworkDeepProbe
./NetworkDeepProbe
```

The default command writes the deep-only schema 1.2 report, including optional platform Wi-Fi and route-table capability fields. Run `NetworkDeepProbe --help` for all controls.

## First-party Internet transfer

Add the Quick, Full, Stress and Compare, Single, Aggregate concepts used by the browser and desktop applications:

```bash
./NetworkDeepProbe --internet-transfer --profile quick --transfer-method compare
```

This mode contacts the project-operated `network.johnnyli.dev` ping, download, and upload endpoints and emits combined schema 2.0. It includes separate single and aggregate measurements where selected, loaded latency, transfer caps, estimated time, and the Stress 1, 2, 4, 8, and 10 connection sequence.

Full and Stress can transfer substantial data. Review the plan printed before the run and avoid metered or cellular connections unless the data use is acceptable.

## Local-link throughput isolation

Use two machines on the same trusted local network. On a preferably wired machine:

```bash
./NetworkDeepProbe --lan-server
```

On the device being tested, replace the address with one printed by the server:

```bash
./NetworkDeepProbe --lan-target 192.168.1.10
```

The client report contains the LAN result and regular deep diagnostics. TCP port 8765 is used by default. Permit it only on trusted firewall profiles and stop the server with Ctrl+C afterward.

## macOS security notice

The current macOS binaries are not Apple-signed or notarized. Review the source and checksum, build from source, or explicitly approve the binary in **System Settings → Privacy & Security** if you trust it. Do not disable Gatekeeper globally.

## Privacy

The default deep-only probe contains no telemetry or speed-payload upload code. It does send the selected ICMP, DNS, traceroute, and TLS diagnostic traffic. `--internet-transfer` intentionally exchanges generated payloads with project-operated endpoints. LAN mode exchanges generated bytes only with the explicitly selected local machine.

Reports omit public IP as a dedicated field, MAC address, hostname, SSID, local interface addresses, gateways, resolver addresses, private route gateways, and private traceroute hops by default. `--include-addresses` deliberately adds available local identifiers, route addresses, and SSID, so review that report before sharing it.

Public traceroute hops and operating-system/interface descriptions can still reveal network or hardware context.
